# Terminal

Copy this folder into the `Themes` directory inside your Spicetify config
directory. Enable it with:

```powershell
spicetify config current_theme Terminal color_scheme Terminal inject_css 1 inject_theme_js 1 replace_colors 1
spicetify apply
```

Press **F8** to show or hide native window controls on the tested Windows client.
For installation details, customization, compatibility, and the preview, see the
[repository README](../README.md).
